# Font Files Needed

Please add the following font files to this directory:

1. **Sentient-Extralight.woff** - Custom font (weight: 200, normal style)
2. **Sentient-LightItalic.woff** - Custom font (weight: 300, italic style)

These fonts are referenced in `app/globals.css`.

## Temporary Workaround

The site will still work without these fonts - it will fall back to the system sans-serif font family.

## Where to Get These Fonts

You can:
1. Use your existing Sentient font files
2. Replace with similar fonts from Google Fonts
3. Or continue with the fallback fonts for now

The rest of the styling will work perfectly!
